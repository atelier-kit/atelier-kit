# Atelier-Kit adapter: Antigravity

Use the adapter instruction file `.antigravity/atelier.md` (installed by Atelier).

- Planning stays Antigravity-native until someone explicitly runs `/atelier ...`.
- `/atelier quick|plan|deep ...` activates Atelier; bootstrap the epic by following `.atelier/skills/bootstrap.md`.
- When active, read `.atelier/active.json`, the active epic `state.json`, and only `.atelier/skills/<active_skill>.md`.
- At `planned`, implement with Antigravity's native workflow from `.atelier/epics/<active_epic>/plan.md` (or an optional native mirror), then follow `.atelier/skills/reviewer.md` to write `review.md`.
